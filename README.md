# GYGY5.0 Kotlin

Bu repo, Turkcell tarafından düzenlenen **Gençlere Yatırım, Geleceğe Yazılım 5.0** eğitim programı kapsamında geliştirdiğim çalışmaları içermektedir.

Repository içerisinde eğitim sürecinde hazırladığım örnek uygulamalar, öğrendiğim konular üzerine yaptığım pratikler ve program kapsamında verilen ödevler yer almaktadır.

Amacım, eğitim boyunca edindiğim bilgi ve deneyimleri düzenli bir şekilde arşivlemek, gelişim sürecimi takip edebilmek ve Kotlin / Android geliştirme alanındaki çalışmalarımı tek bir yerde toplamaktır.

## İçerik

- Kotlin temel ve orta seviye uygulamalar
- Android geliştirme pratikleri
- Jetpack Compose örnekleri
- Eğitim sürecinde verilen ödevler
- Mini projeler ve denemeler
